# UmeedAI Backend

A TypeScript Express backend for the UmeedAI project. Provides REST endpoints for authentication, student records, attendance, academics and risk reporting. Designed to be run locally with `tsx` during development or compiled with `tsc` for production.

## Why this project is useful

- Lightweight TypeScript Express server with modular routes and controllers
- Clear folder structure for models, controllers, and routes
- Postman collection included for quick API testing
- Easy development workflow using `tsx` to run TypeScript directly

## Quick start

Prerequisites:
- Node.js (16+ recommended)
- npm (or pnpm/yarn)
- (Optional) A `.env` file for environment variables if you add configuration
